# Contributing

Thanks for improving Bookmark Cleaner.

1. Fork the repository and create a focused branch.
2. Use Node.js 20+ and run `npm install`.
3. Keep parsing/cleaning deterministic and local-only by default.
4. Add tests for behavioral changes.
5. Run `npm run lint` and `npm test` before opening a pull request.
6. Never commit real browser exports containing private URLs, tokens, or personal data.

Please keep pull requests small and explain user-visible behavior changes.
